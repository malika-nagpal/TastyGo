# TastyGo-Food Delivery Application

TastyGo is a university group project developed for **CP317: Software Engineering** by **Group 8, consisting of 11 team members**. The project focuses on designing and developing a food delivery application that simplifies the food ordering experience while supporting restaurant operations and customer interaction.

## Project Overview

The objective of TastyGo is to provide a user-friendly platform where customers can explore food options, interact with restaurant listings, and go through the food ordering process.

The application was designed around two main user groups: customers and restaurant administrators. Customers can browse food options and interact with the ordering interface, while restaurant administrators are intended to manage restaurant information, menus, orders, and customer feedback.

## Project Objectives

- Develop a functional and user-friendly food delivery application.
- Simplify the process of browsing food options and placing orders.
- Support restaurant menu and order management.
- Provide an interface for customer feedback and reviews.
- Improve the overall food ordering and restaurant management experience.

## Application Features

The project repository includes the following interfaces and components:

- **Homepage:** Food categories, restaurant listings, and food discovery interface.
- **User Authentication:** Login and registration interfaces.
- **Food Browsing:** Food gallery and category-based filtering.
- **Shopping Cart and Checkout:** Interfaces supporting the order checkout process.
- **Order Confirmation:** Displays order confirmation information.
- **User Dashboard:** Dashboard interface for user-related functionality.
